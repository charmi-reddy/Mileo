Commute Hours App Map

This app is a small local proof of concept built around one commute-learning loop.

  • Setup screen: route name, commute minutes, session selection.
  • Validation: the chosen session must fit within the commute time.
  • Study loop: show one Python flashcard, reveal the answer, mark understood or review again.
  • Confirmation: ask for actual minutes and save only valid values.
  • Dashboard: weekly hours reclaimed, daily bar chart, recent sessions list.
  • Correction: delete a mistaken saved session, then update totals immediately.

Key runtime files:

  • app.py — Flask API and route setup
  • static/js/app.js — UI flow, validation, dashboard updates
  • static/css/style.css — mobile-first styling
  • src/db.py — SQLite operations (planned structure)
